Small fix release on top of BRLoop 1.0.0.

- **Version button**: the channel-pair button is back under the speed button, with its "Version:" label. Press it to switch to the next pair. It is disabled when the file has only one pair.
- **Version button text**: the button now shows its caption again (for example "Version 1 · channels 1-2").
- **File information**: the card no longer hides its last row (Duration and Loop) when the window is short. The minimum window height is now 570 px at 96 DPI.

Known limitation: on displays with 150 % scaling or more, resizing the window below 760 x 570 px can still give a window that is smaller than the layout needs.
