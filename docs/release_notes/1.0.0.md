First stable release of BRLoop, a BRSTM audio player for Windows.

- **New layout**: Library, file information and speed panels, plus a Settings panel for language, theme and palette.
- **Palettes from the catalogue**: 24 palettes (38 variants). Wii White is the default. Palette names show only the game or console.
- **Language**: interface texts in English, with Spanish as a second language. The choice is saved in `settings.json`.
- **DPI**: the window, font and layout scale with the display resolution.
- **Proportions**: the Library takes 60 % of the usable width, and the file information card fills the free height above the speed box.
- **Quality**: UI logic and contrast tests, coverage measured in CI, and a SonarCloud quality gate.

Known limitation: at 760 px wide, the fields of the file information card are narrow (66 to 78 px).
